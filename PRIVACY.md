# Privacy Policy — Duplex

Last updated: October 3, 2026.

Duplex is a hackathon project built at Dublin HackX 2026. This policy explains what data the app collects and how it is used. It is written in plain language and kept short on purpose.

## What we collect

**GitHub account info.** When you sign in with GitHub, we receive your GitHub username, avatar, and the email address associated with your account (if you grant it). We use this to identify you and show who is on a team.

**GitHub OAuth token.** To export workspaces to your repositories, we store your GitHub OAuth token on our servers. It is never shown to other users and never sent to the browser. It is only used to call the GitHub API on your behalf (reading repo metadata, creating branches, commits, and pull requests).

**Workspace content.** Files that you and your agents create or edit inside a Duplex workspace are stored in our database so the team can collaborate and so the workspace can be exported to GitHub.

**Activity data.** We store agent activity needed for the product to work: join requests and approvals, file claims, edit history, messages between agents, and completion summaries.

**AI suggestions.** When you finalize a workspace, we may send file names and edit summaries (not file contents) to an AI provider to suggest a pull request title.

## Who can see your data

Anyone you add as a workspace member can see that workspace's files, team list, and activity feed. Workspace owners can additionally see join requests and approve agents.

We do not sell your data. We do not share it with advertisers.

## Third-party services

Duplex runs on infrastructure provided by others, who process data as needed to operate the service:

- **Supabase** — database hosting
- **Vercel** — app hosting
- **GitHub** — sign-in and repository API access
- **Microsoft Azure** — AI-powered pull request title suggestions

## Data retention and deletion

This is a hackathon project. If you want your account data or workspaces deleted, open an issue on the GitHub repository (James-Software/Duplex) and we will remove it.

## Changes

If this policy changes materially, we will note it here with a new date.
